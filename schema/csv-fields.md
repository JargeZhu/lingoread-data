# CSV 字段规范

三套 CSV 共用一套解析器（LingoRead `lib/services/import/`），规则完全一致：

- **编码**：UTF-8（推荐）/ UTF-8 带 BOM / GBK 都能读，按 BOM → UTF-8 → GBK 顺序尝试。
- **分隔符**：`Tab` > `;` > `,` > `，`，取"所有行切出宽度一致"的那个；都不一致就用 `,`。
- **引号**：支持 `"` 包裹含分隔符的字段，`""` 表示一个引号字符。
- **体积上限**：2 MB。
- **换行**：LF 或 CRLF 都可。

## 表头识别

首行命中 **≥ 2 个**列名别名才算表头（单列命中有歧义，容易把数据行误判成表头）。

带表头时**列顺序任意**，按别名映射；不带表头时按下面的固定列序解读。

匹配规则：先找完全相同的列名；找不到再看**列名里是否包含**某个别名——所以
「文章标题」会被认成「标题」、「英文句子」会被认成「英文」，不用一字不差。
例外是 `en` / `zh` / `ipa` 这类三字母以内的英文缩写，它们只做完全匹配，
否则 `when`、`then` 这种普通单词会被误认成表头。

## 单词 `words/*.csv`

| 列 | 必填 | 识别别名 |
|---|---|---|
| 库名 | 否 | `库名` `词库` `词库名` `library` |
| 单词 | ✅ | `单词` `英文` `word` `english` |
| 音标 | 否 | `音标` `拼音` `phonetic` `ipa` |
| 释义 | ✅ | `释义` `中文` `意思` `meaning` `translation` |
| 例句 | 否 | `例句` `句子` `example` `sentence` |

无表头时的列序（**取决于列数，不是简单截断**）：

| 列数 | 列序 |
|---|---|
| 5 | 库名 / 单词 / 音标 / 释义 / 例句 |
| 4 | 单词 / 音标 / 释义 / 例句 |
| 3 | 单词 / 音标 / 释义 |

> 「库名」留空时，单词会进导入页面上选中的目标库；非空则按该名称建库/归库。

## 朗读 `reading/*.csv`

| 列 | 必填 | 识别别名 |
|---|---|---|
| 文章标题 | ✅ | `标题` `文章` `文章标题` `篇名` `title` |
| 教材 | 否 | `教材` `课本` `textbook` |
| 年级 | 否 | `年级` `grade` |
| 单元 | 否 | `单元` `unit` |
| 英文句子 | ✅ | `英文` `英文句子` `en` `english` |
| 中文句子 | ✅ | `中文` `中文句子` `译文` `zh` `chinese` |
| 库名 | 否 | `库名` `朗读库` `library` |

无表头时的列序：

| 列数 | 列序 |
|---|---|
| 6 及以上 | 标题 / 教材 / 年级 / 单元 / 英文 / 中文 [/ 库名] |
| 3 ~ 5 | 标题 / 英文 / 中文 [/ 库名] |

**合并规则**：同一个「标题」的多行会合并成一篇；按文件中**首次出现顺序**排列句子。
标题留空时沿用上一行的标题，库名同理——这样导出「合并单元格」式的表格也能用。

## 金句 `motto/*.csv`

| 列 | 必填 | 识别别名 |
|---|---|---|
| 英文金句 | ✅ | `英文` `英文金句` `金句` `en` `english` |
| 中文译文 | ✅ | `中文` `译文` `中文译文` `zh` `chinese` |
| 分类 | 否 | `分类` `类别` `category` |
| 库名 | 否 | `库名` `金句库` `library` |

无表头时的列序：英文 / 中文 / 分类 / 库名。

> 分类留空默认 `励志`；库名留空沿用上一行。

## 常见坑

| 现象 | 原因 |
|---|---|
| 导入后 0 条 | 贴成了网页地址（返回 HTML），或表头写错导致首行被当数据 |
| 音标列显示成释义 | 无表头且列数改成 4 列以下，列序被按另一套规则解读 —— 加表头最稳 |
| 只有部分行导入 | 各行列数不一致，解析器会跳过异常行 |
| Excel 打开中文乱码 | 存成了 GBK。另存为「CSV UTF-8」 |
| 文件下不下来 | 用了 `cdn.jsdelivr.net`，或仓库/分支是私有的 |
